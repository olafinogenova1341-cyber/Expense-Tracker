# Expense Tracker

**Автор:** Финогенов Илья

## Описание программы

Expense Tracker — это простое GUI‑приложение для отслеживания личных расходов. Программа позволяет:

* Добавлять расходы с указанием суммы, категории и даты.
* Фильтровать записи по категориям и датам.
* Подсчитывать общую сумму расходов за выбранный период.
* Сохранять и загружать данные в формате JSON.

Приложение создано на Python с использованием стандартной библиотеки Tkinter.

## Технические требования

* Python 3.6 или выше.
* Стандартные библиотеки: `tkinter`, `datetime`, `json`, `os`.
